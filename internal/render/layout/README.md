# 渲染布局计算

本目录集中存放渲染核心的布局与坐标计算，各子包按图元职责划分。

| 子包 | 职责 |
|---|---|
| `text` | 字形映射、字符与字形定位、文字提取所需的字符区域 |
| `image` | 图片放置矩阵、边框及图片局部裁剪 |
| `composite` | 复合图元尺寸兼容、保守墨迹边界与重采样计划 |
| `pattern` | 底纹平铺范围、步长、镜像及图块变换 |
| `seal` | 印章目标裁剪框与源图像素区域 |

各子包只计算布局，不持有文档资源及其缓存或绘制上下文。模型、定位数组及共享
路径视为只读；需要变换路径时创建副本。字体度量由调用方提供，并由调用方按
字体实现约定持锁。

导入时可使用 `textlayout`、`imagelayout` 等别名，使调用含义明确，并避免与标准库
`image` 或局部变量重名。

在仓库根目录运行布局测试：

```sh
go test ./internal/render/layout/...
```
