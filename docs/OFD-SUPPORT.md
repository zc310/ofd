# OFD 标准支持清单

本文档根据当前仓库中的解析器、校验器、创建器、渲染器、命令行工具和阅读器整理，主要参考 GB/T 33190-2016《电子文件存储与交换格式 版式文档》及仓库内置的 OFD Schema。

本文档描述的是项目当前的实现范围，不代表项目已经完整实现或通过了 OFD 标准符合性认证。不同厂商生成的 OFD 文件可能使用标准扩展、历史兼容写法或未被测试的组合特性，实际使用前仍应使用目标业务样本验证。

## 支持级别

| 级别     | 含义                                                                       |
|----------|----------------------------------------------------------------------------|
| 已支持   | 已有对应的解析、校验、创建、渲染或阅读实现，并有测试或实际样例依据。       |
| 部分支持 | 可以识别或处理主要结构，但部分属性、组合场景、视觉效果或业务语义仍有限制。 |
| 暂不支持 | 当前没有完整实现，或项目明确不对该能力作支持承诺。                         |

## 核心格式

| 标准范围                  | 当前状态 | 说明                                                                                                      |
|---------------------------|----------|-----------------------------------------------------------------------------------------------------------|
| OFD ZIP 容器              | 已支持   | 支持读取 ZIP 条目、包内路径、条目大小和压缩数据；对路径穿越、绝对路径、重复条目和解压大小进行限制或检查。 |
| `OFD.xml` 和 `DocBody`    | 已支持   | 支持入口文件、版本、文档类型、多个文档体及文档根路径。多个文档体按文件顺序处理。                          |
| XML 命名空间              | 已支持   | 校验器内置 `http://www.ofdspec.org/2016` 命名空间检查。                                                   |
| 文档、页面和资源相对路径  | 已支持   | 按引用文件所在目录解析 `BaseLoc`、`PageRes`、`MediaFile`、`FontFile`、模板、附件和签名文件。              |
| 多文档体和全局页码        | 已支持   | 转换器、分析器、桌面阅读器和 WASM 阅读器都支持按 `DocBody` 顺序合并页面。                                 |
| 文档级 `CommonData`       | 已支持   | 支持页面区域、公共资源、文档资源、模板页、默认颜色空间等常用字段。                                        |
| 页面级 `Area/PhysicalBox` | 已支持   | 支持页面独立物理尺寸；缺少页面尺寸时可回退到文档级页面区域。                                              |

## 页面内容

| 标准范围                   | 当前状态 | 说明                                                                                                                  |
|----------------------------|----------|-----------------------------------------------------------------------------------------------------------------------|
| 页面 `Template` 引用       | 部分支持 | 支持读取、缓存和绘制模板页；模板的背景层和前景层语义仍不是所有场景都完整覆盖。                                        |
| 页面 `PageRes`             | 已支持   | 支持页面级资源 XML 和资源文件的读取与引用。                                                                           |
| `Layer` 和页面绘制顺序     | 已支持   | 支持背景层优先处理，并保留页面块内对象的 XML 顺序。                                                                   |
| 文字对象 `TextObject`      | 部分支持 | 支持文字内容、字号、字体、位置、字符间距、字重、斜体、CTM、字形变换和文字层提取；复杂排版方向和部分字体特性仍有限制。 |
| 路径对象 `PathObject`      | 已支持   | 支持移动、直线、二次/三次贝塞尔曲线、椭圆弧、闭合路径、描边、填充、线型和填充规则。                                   |
| 图片对象 `ImageObject`     | 部分支持 | 支持图片变换、透明度、常见栅格图片、SVG、裁剪和图片缓存；图片边框等效果并非全部已渲染。                               |
| 复合图元 `CompositeObject` | 部分支持 | 支持复合图元定义、引用、递归绘制和常见裁剪；复杂嵌套或特殊组合可能采用限制或栅格回退。                                |
| 嵌套 `PageBlock`           | 已支持   | 支持将页面对象组织为嵌套块并参与绘制、文字提取和分析。                                                                |
| 六参数 `CTM`               | 已支持   | 文字、路径、图片、复合图元和裁剪区域支持坐标变换。                                                                    |
| `Clips` 裁剪               | 部分支持 | 支持路径、文字和组合裁剪；复杂裁剪可能转为像素掩码，视觉效果和性能依赖具体文件。                                      |

## 资源和视觉效果

| 标准范围                       | 当前状态 | 说明                                                                                                                                           |
|--------------------------------|----------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `DrawParam` 及 `Relative` 继承 | 已支持   | 支持线宽、线端、线连接、斜接限制、虚线、填充色、描边色和继承关系。                                                                             |
| 颜色空间和调色板               | 部分支持 | 支持常用颜色空间、颜色分量、调色板和资源引用；特殊颜色空间组合需要使用实际样本验证。                                                           |
| 轴向渐变和径向渐变             | 部分支持 | 支持常见渐变绘制；部分输出格式或复杂渐变会采用栅格化回退。                                                                                     |
| 网格渐变                       | 部分支持 | 支持部分 Gouraud/LaGouraud 网格渐变，并使用高 DPI 栅格化路径；复杂场景可能与原始显示存在差异。                                                 |
| `Pattern`                      | 部分支持 | 支持图案单元、步长、CTM 和常见路径填充；存在瓦片数量和离屏像素保护限制。                                                                       |
| 透明度和 Alpha                 | 部分支持 | 支持对象、颜色和图片的常见透明度；不同输出格式对透明通道的处理可能不同。                                                                       |
| 字体声明和嵌入字体             | 部分支持 | 支持 TTF、OTF、TTC 等常见字体资源、嵌入字体读取、字体修复和外部回退字体；字体子集、特殊 CFF、字形映射和复杂排版可能需要单独验证。              |
| 图片格式                       | 部分支持 | 栅格图片解码支持 PNG、JPEG、GIF、BMP、WebP、TIFF 等常见格式；SVG 支持解析和部分场景的矢量绘制。具体 OFD 图片格式声明及厂商扩展仍需按样本验证。 |

## 附加结构

| 标准范围                | 当前状态 | 说明                                                                                                                                       |
|-------------------------|----------|--------------------------------------------------------------------------------------------------------------------------------------------|
| 页面注解和注解外观      | 部分支持 | 支持注解文件、页面关联、常见 `Stamp`、`Link` 等结构读取和部分外观绘制。                                                                    |
| 动作 `Actions`          | 部分支持 | 支持常见页面跳转、URI、文档跳转、声音和影片等结构的读取或创建；桌面、WASM 和导出格式不会完整执行所有动作。                                 |
| 附件 `Attachments`      | 已支持   | 支持附件清单、文件引用、路径解析、分析和创建。阅读器不会自动执行附件内容。                                                                 |
| 自定义标签 `CustomTags` | 已支持   | 支持按需读取、分析和校验自定义标签结构。                                                                                                   |
| 扩展 `Extensions`       | 已支持   | 支持扩展元数据、属性和内联或外部扩展数据的读取与校验。                                                                                     |
| 文档版本 `Versions`     | 已支持   | 支持版本清单和版本文件的按需读取。                                                                                                         |
| 大纲、书签和阅读偏好    | 部分支持 | 文档模型支持这些 XML 结构的读取，创建器支持生成其中的常见结构；阅读器目前不会完整提供大纲/书签面板，也不会完整执行所有页面模式和显示偏好。 |
| 权限声明                | 部分支持 | 文档模型和创建器支持权限字段；解析、转换和阅读流程不会自动强制执行全部权限，调用方仍需自行决定是否执行权限策略。                           |

## 数字签名和电子印章

| 标准范围                            | 当前状态 | 说明                                                                                                                          |
|-------------------------------------|----------|-------------------------------------------------------------------------------------------------------------------------------|
| `Signatures.xml` 和 `Signature.xml` | 已支持   | 支持签名清单、签名描述、签名引用、签名时间、签章关联和包内路径检查。                                                          |
| 签名摘要                            | 已支持   | 支持 MD5、SHA1、SM3 以及 SM3 OID `1.2.156.10197.1.401` 的摘要计算和比对。                                                     |
| SignedValue ASN.1 结构              | 部分支持 | 支持通用 ASN.1 树和常见 SES 电子印章结构解析。非标准或厂商扩展数据可能只能保留原始内容。                                      |
| SM2/SES 签名验证                    | 部分支持 | 支持部分签名值格式、签名算法和可选证书链/CRL 校验配置；默认不加载系统根证书，不能据此直接判断法律效力、身份真实性或证书信任。 |
| 电子印章外观                        | 部分支持 | 支持从常见签章数据中提取印章图像并绘制；嵌入 OFD、厂商封装和复杂印章外观需要按样本验证。                                      |

## 校验器和工具支持

| 能力                              | 当前状态 | 说明                                                                                                                                                                                               |
|-----------------------------------|----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 内置 OFD XSD                      | 已支持   | 内置 `OFD`、`Document`、`Page`、`Res`、`Signatures`、`Signature`、`Annotations`、`PageAnnot`、`Attachments`、`CustomTags`、`Extensions` 和 `DocVersion` 等根模式；XSD 通过 `go:embed` 随程序发布。 |
| 校验模式                          | 已支持   | 支持 `strict`、`compat` 和 `structural` 模式，并输出文本、Markdown、JSON 和 PDF 报告。                                                                                                             |
| 容器、XML、引用和语义检查         | 已支持   | 支持 XML 结构、命名空间、文件引用、对象 ID、资源作用域、路径安全和多项语义检查。                                                                                                                   |
| OFD 转 PDF、图片、文本和 Markdown | 部分支持 | 支持常见页面内容和资源转换；特殊字体、复杂渐变、透明、裁剪、模板、印章和厂商扩展可能造成输出差异。                                                                                                 |
| 桌面、Android 和 WASM 阅读器      | 部分支持 | 提供 Linux、Windows、Android APK 和浏览器阅读入口；各运行环境的字体、图形库和系统能力不同。                                                                                                        |

## 当前明确的边界

以下内容不能按“完整支持 GB/T 33190-2016”理解：

- 不保证所有标准可选项、组合属性和厂商扩展都能正确解析或渲染。
- 不保证 PDF、PNG、SVG、文本提取结果与原始版式完全一致。
- 复杂字体子集、特殊 CFF、复杂排版方向、字形映射和未嵌入字体需要单独验证。
- 复杂渐变、Pattern、透明度、裁剪、模板层次和复合图元可能使用栅格回退或受到资源预算限制。
- 数字签名、证书链、吊销状态和电子印章验证结果不能单独作为法律或合规结论。
- 当前未提供通用 OFD 加密文档解密能力，也不会执行附件、脚本或外部内容。

## 验证建议

正式使用前，建议至少使用以下方式验证目标文件：

```bash
# 严格校验文件结构和引用
go run ./cmd/ofd-validator --format text --mode strict test.ofd

# 分析页面、资源、字体、附件、注解和签名
go run ./cmd/ofd-analyzer --format text test.ofd

# 转换为 PDF 进行视觉对比
go run ./cmd/ofd-converter -format pdf test.ofd output.pdf
```

重点准备包含目标字体、图片格式、页面方向、模板、裁剪、渐变、印章、附件和签名的真实业务样本，并分别在 Linux、Windows、Android 和浏览器环境中验证。
