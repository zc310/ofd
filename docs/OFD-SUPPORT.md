# OFD 标准支持清单

本文档根据当前仓库中的解析器、校验器、创建器、渲染器、命令行工具和阅读器整理，主要参考 GB/T 33190-2016《电子文件存储与交换格式 版式文档》及仓库内置的 OFD Schema。

本文档描述的是项目当前的实现范围，不代表项目已经完整实现或通过了 OFD 标准符合性认证。不同厂商生成的 OFD 文件可能使用标准扩展、历史兼容写法或未被测试的组合特性，实际使用前仍应使用目标业务样本验证。

## 支持级别

| 图标 | 级别     | 含义                                                                       |
|:----:|----------|----------------------------------------------------------------------------|
|  ✅  | 已支持   | 已有对应的解析、校验、创建、渲染或阅读实现，并有测试或实际样例依据。       |
|  ⚠️  | 部分支持 | 可以识别或处理主要结构，但部分属性、组合场景、视觉效果或业务语义仍有限制。 |
|  ❌  | 暂不支持 | 当前没有完整实现，或项目明确不对该能力作支持承诺。                         |

## 核心格式

| 标准范围                  | 状态 | 说明                                                                                                      |
|---------------------------|:----:|-----------------------------------------------------------------------------------------------------------|
| OFD ZIP 容器              |  ✅  | 支持读取 ZIP 条目、包内路径、条目大小和压缩数据；对路径穿越、绝对路径、重复条目和解压大小进行限制或检查。 |
| `OFD.xml` 和 `DocBody`    |  ✅  | 支持入口文件、版本、文档类型、多个文档体及文档根路径。多个文档体按文件顺序处理。                          |
| XML 命名空间              |  ✅  | 校验器内置 `http://www.ofdspec.org/2016` 命名空间检查。                                                   |
| 文档、页面和资源相对路径  |  ✅  | 按引用文件所在目录解析 `BaseLoc`、`PageRes`、`MediaFile`、`FontFile`、模板、附件和签名文件。              |
| 多文档体和全局页码        |  ✅  | 转换器、分析器、桌面阅读器和 WASM 阅读器都支持按 `DocBody` 顺序合并页面。                                 |
| 文档级 `CommonData`       |  ✅  | 支持页面区域、公共资源、文档资源、模板页、默认颜色空间等常用字段。                                        |
| 页面级 `Area/PhysicalBox` |  ✅  | 支持页面独立物理尺寸；缺少页面尺寸时可回退到文档级页面区域。                                              |

## 页面内容

| 标准范围                   | 状态 | 说明                                                                                                                  |
|----------------------------|:----:|-----------------------------------------------------------------------------------------------------------------------|
| 页面 `Template` 引用       |  ⚠️  | 支持读取、缓存和绘制模板页；模板的背景层和前景层语义仍不是所有场景都完整覆盖。                                        |
| 页面 `PageRes`             |  ✅  | 支持页面级资源 XML 和资源文件的读取与引用。                                                                           |
| `Layer` 和页面绘制顺序     |  ✅  | 支持背景层优先处理，并保留页面块内对象的 XML 顺序。                                                                   |
| 文字对象 `TextObject`      |  ⚠️  | 支持文字内容、字号、字体、位置、字符间距、字重、斜体、CTM、字形变换和文字层提取；复杂排版方向和部分字体特性仍有限制。 |
| 路径对象 `PathObject`      |  ✅  | 支持移动、直线、二次/三次贝塞尔曲线、椭圆弧、闭合路径、描边、填充、线型和填充规则。                                   |
| 图片对象 `ImageObject`     |  ⚠️  | 支持图片变换、透明度、常见栅格图片、SVG、裁剪和图片缓存；图片边框等效果并非全部已渲染。                               |
| 复合图元 `CompositeObject` |  ⚠️  | 支持复合图元定义、引用、递归绘制和常见裁剪；复杂嵌套或特殊组合可能采用限制或栅格回退。                                |
| 嵌套 `PageBlock`           |  ✅  | 支持将页面对象组织为嵌套块并参与绘制、文字提取和分析。                                                                |
| 六参数 `CTM`               |  ✅  | 文字、路径、图片、复合图元和裁剪区域支持坐标变换。                                                                    |
| `Clips` 裁剪               |  ⚠️  | 支持路径、文字和组合裁剪；复杂裁剪可能转为像素掩码，视觉效果和性能依赖具体文件。                                      |

## 资源和视觉效果

| 标准范围                       | 状态 | 说明                                                                                                                                                                                                                       |
|--------------------------------|:----:|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DrawParam` 及 `Relative` 继承 |  ✅  | 支持线宽、线端、线连接、斜接限制、虚线、填充色、描边色和继承关系。                                                                                                                                                         |
| 颜色空间和调色板               |  ⚠️  | 支持 GRAY/RGB/CMYK 颜色分量、调色板、资源引用，以及 `ColorSpace.Profile` 指定的 ICC 配置文件转换；CMYK 无配置文件时按减色油墨模型近似，特殊颜色空间组合仍需按样本验证。                                                    |
| 轴向渐变和径向渐变             |  ⚠️  | 支持常见渐变绘制；部分输出格式或复杂渐变会采用栅格化回退。                                                                                                                                                                 |
| 网格渐变                       |  ⚠️  | 支持读取 OFD 的 Gouraud/LaGouraud 网格并绘制；渲染时构建均匀网格空间索引，把逐像素采样限制在少量候选三角形内（大型网格从逐点全量遍历的微秒级降到几十纳秒）。PDF 转换器据此把网格着色优先输出为矢量网格，超限时才回退位图。 |
| `Pattern`                      |  ⚠️  | 支持图案单元、步长、CTM 和常见路径填充；存在瓦片数量和离屏像素保护限制。                                                                                                                                                   |
| 透明度和 Alpha                 |  ⚠️  | 支持对象、颜色和图片的常见透明度；不同输出格式对透明通道的处理可能不同。                                                                                                                                                   |
| 字体声明和嵌入字体             |  ⚠️  | 支持 TTF、OTF、TTC 等常见字体资源、嵌入字体读取、字体修复和外部回退字体；字体子集、特殊 CFF、字形映射和复杂排版可能需要单独验证。                                                                                          |
| 图片格式                       |  ⚠️  | 栅格图片解码支持 PNG、JPEG、GIF、BMP、WebP、TIFF 等常见格式；SVG 支持解析和部分场景的矢量绘制。具体 OFD 图片格式声明及厂商扩展仍需按样本验证。                                                                             |

## 附加结构

| 标准范围                | 状态 | 说明                                                                                                                                                                                                                                                                                                                                                                        |
|-------------------------|:----:|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 页面注解和注解外观      |  ⚠️  | 支持注解文件、页面关联、常见 `Stamp`、`Link` 等结构读取和部分外观绘制。                                                                                                                                                                                                                                                                                                     |
| 动作 `Actions`          |  ⚠️  | 支持常见页面跳转、URI、文档跳转、声音和影片等结构的读取或创建；桌面、WASM 和导出格式不会完整执行所有动作。                                                                                                                                                                                                                                                                  |
| 附件 `Attachments`      |  ✅  | 支持附件清单、文件引用、路径解析、分析和创建。阅读器不会自动执行附件内容。                                                                                                                                                                                                                                                                                                  |
| 自定义标签 `CustomTags` |  ✅  | 支持按需读取、分析和校验自定义标签结构。                                                                                                                                                                                                                                                                                                                                    |
| 扩展 `Extensions`       |  ✅  | 支持扩展元数据、属性和内联或外部扩展数据的读取与校验。                                                                                                                                                                                                                                                                                                                      |
| 文档版本 `Versions`     |  ✅  | 支持版本清单和版本文件的按需读取。                                                                                                                                                                                                                                                                                                                                          |
| 大纲、书签和阅读偏好    |  ⚠️  | 文档模型支持这些 XML 结构的读取，创建器支持生成其中的常见结构；WASM 阅读器提供可折叠的大纲面板和书签列表，支持按 `PageMode` 默认打开、按 `Dest` 的 `Top`/`Left`/`Zoom`（含 `FitR` 与旋转页面坐标）定位，并在用户未保存偏好时应用文档声明的 `PageLayout`/`ZoomMode`（`FitHeight`/`FitRect` 近似为适应页面）。`HideToolbar`/`HideMenubar`/`HideWindowUI` 等界面偏好尚未执行。 |
| 权限声明                |  ⚠️  | 文档模型和创建器支持权限字段；解析、转换和阅读流程不会自动强制执行全部权限，调用方仍需自行决定是否执行权限策略。                                                                                                                                                                                                                                                            |

## 数字签名和电子印章

| 标准范围                            | 状态 | 说明                                                                                                                          |
|-------------------------------------|:----:|-------------------------------------------------------------------------------------------------------------------------------|
| `Signatures.xml` 和 `Signature.xml` |  ✅  | 支持签名清单、签名描述、签名引用、签名时间、签章关联和包内路径检查。                                                          |
| 签名摘要                            |  ✅  | 支持 MD5、SHA1、SM3 以及 SM3 OID `1.2.156.10197.1.401` 的摘要计算和比对。                                                     |
| SignedValue ASN.1 结构              |  ⚠️  | 支持通用 ASN.1 树和常见 SES 电子印章结构解析。非标准或厂商扩展数据可能只能保留原始内容。                                      |
| SM2/SES 签名验证                    |  ⚠️  | 支持部分签名值格式、签名算法和可选证书链/CRL 校验配置；默认不加载系统根证书，不能据此直接判断法律效力、身份真实性或证书信任。 |
| 电子印章外观                        |  ⚠️  | 支持从常见签章数据中提取印章图像并绘制；嵌入 OFD、厂商封装和复杂印章外观需要按样本验证。                                      |

## 文档合并

`pkg/merge` 与 `ofd-creator merge` 提供两级合并能力。

| 标准范围 / 能力            | 状态 | 说明                                                                                                                                                                                    |
|----------------------------|:----:|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ZIP 级合并（多文档体打包） |  ✅  | 把多个 OFD 的文档体原样搬运到新的 `Doc_0…Doc_N` 目录，只重写 `OFD.xml` 与签名文件中的包内路径；不解析页面和资源，资源 ID 无需重映射。                                                   |
| ZIP 级签名处理                          | ⚠️ | `preserve`（默认，无法保留时报错）、`rewrite`（重写路径、签名值失效）、`drop`（删除签名）三种方式；合并汇总每个签名的处理结果，`--verify-signatures` 可校验输出签名的摘要与密码学签名。不提供内置重新签名。 |
| 外部命令重新签名                        | ⚠️ | `pkg/sign` / `ofd-creator merge --sign-cmd` 为每个文档体生成 `Signature.xml` 并把该文件交给外部命令，读回其输出的 `SignedValue.dat`。密钥与密码学算法由外部命令负责，项目不内置签名算法；`cmd/ofd-signer-demo` 是最小示例签名器（SM2 自签名，仅演示/测试）。 |
| 目录外条目与规模限制       |  ✅  | 文档目录之外的条目可 `error`/`ignore`/`preserve`；限制条目数、单条与解压总大小，且不信任 ZIP 声明大小。                                                                                 |
| 模型级合并（跨文档拼页）   |  ⚠️  | `merge.Pages` / `ofd-creator merge --pages` 把各文档体解析为 creator 模型后重新生成单文档；文档级资源（字体名、绘制参数名、图片/颜色空间/复合图元/模板 ID）会重命名或重编号并改写引用。 |
| 选页与重排                 |  ✅  | 支持全局页序（`1,3-5`）与按来源（`s1:1,3-5;s2:2`）选页，可重排；越界报错。                                                                                                              |
| 页面尺寸                   |  ✅  | 保留各来源的逐页 `Area/PhysicalBox`，不同尺寸页面可混合。                                                                                                                               |
| 大纲、书签和动作           |  ✅  | 模型级合并会保留并按其来源与最终页序重写跳转页索引；目标页未保留的动作会被丢弃。                                                                                                        |
| 签名和版本                 |  ❌  | 模型级合并会丢弃签名与版本；合并结果需要重新签名或另行校验。                                                                                                                            |
| 页面注解                   |  ✅  | 模型级合并保留页面注解并按最终页序重写所属页；目标页未保留的注解会被丢弃，同一页的多来源注解会合并。                                                                                    |
| 页面级资源冲突             |  ⚠️  | 页面级资源的 ID/名称已尽量重写，极端结构冲突时由创建器报错而非静默产出错误结果。                                                                                                        |

## 当前明确的边界

以下内容不能按“完整支持 GB/T 33190-2016”理解：

- 不保证所有标准可选项、组合属性和厂商扩展都能正确解析或渲染。
- 不保证 PDF、PNG、SVG、文本提取结果与原始版式完全一致。
- 复杂字体子集、特殊 CFF、复杂排版方向、字形映射和未嵌入字体需要单独验证。
- 复杂渐变、Pattern、透明度、裁剪、模板层次和复合图元可能使用栅格回退或受到资源预算限制。
- 数字签名、证书链、吊销状态和电子印章验证结果不能单独作为法律或合规结论。
- 文档合并不内置重新签名：ZIP 级合并在文档改名后可能使绝对路径签名失效（`rewrite` 会重写路径但签名值失效），模型级合并会丢弃签名和版本；需要重签时通过 `--sign-cmd` 调用外部命令生成 `SignedValue.dat`。
- 当前未提供通用 OFD 加密文档解密能力，也不会执行附件、脚本或外部内容。

## 验证建议

正式使用前，建议至少使用以下方式验证目标文件：

```bash
# 严格校验文件结构和引用
go run ./cmd/ofd-validator --format text --mode strict test.ofd

# 分析页面、资源、字体、附件、注解和签名
go run ./cmd/ofd-analyzer --format text test.ofd

# 转换为 PDF 进行视觉对比
go run ./cmd/ofd-converter -format pdf test.ofd output.pdf

# 合并多个 OFD（ZIP 级多文档体）并严格校验
go run ./cmd/ofd-creator merge -o merged.ofd --validate a.ofd b.ofd

# 模型级选页/重排合并
go run ./cmd/ofd-creator merge -o selected.ofd --pages "s1:1,3-5;s2" --validate a.ofd b.ofd
```

重点准备包含目标字体、图片格式、页面方向、模板、裁剪、渐变、印章、附件和签名的真实业务样本，并分别在 Linux、Windows、Android 和浏览器环境中验证。
