关于 OFD WASM 阅读器

版本：0.1.1

说明：基于 WebAssembly 的 OFD 文档阅读器，支持在浏览器中直接查看 OFD 格式文件。

字体：OFD 内未嵌入字体时，使用 Smiley Sans 作为回退字体。

功能特性：

  • 支持 OFD 文档浏览和缩放
  • 页面缩略图导航
  • 文本搜索和复制
  • 打印和导出功能
  • 深色阅读模式
  • 响应式设计，支持移动端

技术栈：Go + WebAssembly + JavaScript
