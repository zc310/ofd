# Wails 原生阅读器（桌面 / Android，实验性）

程序名为 `ofd-viewer-wails`，源码位于 `cmd/ofd-viewer-wails`，窗口和快捷方式显示名保持 `OFD Reader (Wails)`。

桌面端与 `cmd/ofd-wasm/web` 共用阅读器界面，由原生 Go 并发渲染，不打包或加载
WASM。使用原生文件对话框、拖放单个 `.ofd` 文件或最近文档列表打开 OFD；支持 PNG、JPG、SVG 页面渲染，PNG 缩略图、文字选择、搜索、
文档大纲、书签、页面内链接跳转、正文附件链接、经原生确认后由系统浏览器打开外部链接、正文图层和模板显示控制、基本信息和权限，并支持文档声明的显示偏好。
正式两端的文字合并与定位统一位于 `viewer.js`；旧 `prototype` 页面仅保留独立的历史布局快照供对比，不作为正式界面的共享实现。
页面中可展开有定位边界的可见注解备注，注解清单最多扫描 2000 页、显示 5000 条，截断时显示提示。
SVG 模式中的合成粗体、合成斜体使用与 PNG 相同的已整形矢量轮廓，避免系统 WebView 再次合成字体造成字形或可见字距差异；不人为加宽文档字距，仍保留文字搜索和选择。
支持附件和多媒体资源清单，以及不超过 8 MiB、2500 万像素的 PNG/JPEG/GIF/BMP/TIFF/WebP 图片预览；PNG/JPEG 保留原图，额外格式由 Go 只解码第一帧/页并转换为受限静态 PNG，输出同样最多 8 MiB。不执行 SVG/HTML；GIF 不播放动画，TIFF 不切换后续页。资源清单提供独立“另存为”按钮，不影响预览。信息面板支持字体声明列表、资源统计和字体使用页统计。

资源和印章缩略图仅在侧栏可见区域附近自动加载，无需点击；共用最多两个在途任务的队列。桌面 Go 在相同输入安全限制内完整解码，等比例缩小为长边最多 256 像素的 PNG（小图不放大，保留透明背景），不把完整原图作为缩略图传给网页；资源尺寸标签仍显示原图尺寸。点击大图独立读取原始图片并重新检查权限。取消或文档切换会清除等待队列，不能立即中断的底层解码退出后丢弃结果；无 IntersectionObserver 的环境使用相同有界队列回退。
文本附件支持 TXT、XML、JSON、CSV、Markdown、YAML、LOG、HTML 源码查看：最多 1 MiB，仅接受 UTF-8（可带 BOM），拒绝二进制控制字符，所有标记均以纯文本显示，不执行脚本或加载外部资源。附件也支持上述受限光栅图片及不超过 32 MiB 的音视频预览；每次打开都按导出权限读取。正文附件链接按真实清单中的作用域和 ID 查找，不用链接携带的名称替代缺失附件；可预览类型复用内置预览，PDF、SVG、办公文件及其他未接入格式通过原生对话框另存为，不自动执行或打开。关闭或切换文档、侧栏后丢弃未完成结果。
附件和资源均支持通过原生“另存为”对话框保存原始内容，最大 64 MiB；显示对话框前及实际保存前均检查导出权限（预览权限不能代替导出权限），取消不写文件，禁止覆盖当前输入文档及其符号链接、硬链接。保存后不自动打开或执行文件。对话框未完成时其他原生打开操作等待，不切换到其他文档。
签名面板显示解析时获得的摘要、签名值、完整验证项目和证书详情；未完成的检查不代表通过，证书链与吊销状态需单独确认。逐个签章显示标识、页面和可见边界，点击可跳转并短暂高亮有效边界；也可点击页面中签章的可见区域查看属性。PNG/JPEG/OFD 印章默认加载并显示缩略图，无需点击；点击 PNG/JPEG 缩略图可查看原始完整大图，而非页面裁剪或变换后的效果。缩略图加载和大图打开分别检查所属文档体的访问权限，不要求导出权限，PNG/JPEG 按实际内容限制为 8 MiB、2500 万像素。OFD 印章渲染子文档第一页为透明 PNG，缩略图长边最多 256 像素，大图最多 2048 像素；输入最多 8 MiB、2048 条目，解压每条目最多 8 MiB、总计最多 64 MiB，单张 PNG 输出最多 8 MiB，不执行子文档动作或解锁嵌套加密。预览不代表验证通过；SVG 等其他印章格式仍禁用并提示。印章和资源大图共用可在读取中关闭的弹窗，切换侧栏或文档时取消图片请求并释放缩略图和大图 URL，关闭大图只释放大图资源；权限拒绝或图片解码失败后允许点击重试。

图片与签章大图默认适应窗口且不放大小图；支持按钮、滚轮及 `+`/`−` 键缩放（最低为 10% 或完整适应比例中的较小值，最高 800%），滚轮围绕指针位置缩放。放大后可用鼠标或单指拖动，聚焦图片区域后可用方向键平移；图像边缘受限，不会拖出视区。`100%`/`0` 恢复原始像素大小，`适应窗口`/`F` 自动居中并跟随窗口大小变化，透明图像以棋盘格衬底显示。右上角 `×` 或 `Esc` 关闭，释放拖动、尺寸监听及大图 URL，不改变正文缩放或触发后台翻页。
桌面图片、文本与音视频预览相互替换：打开另一种预览时关闭旧窗口，取消未完成读取和播放权限复核，并停止旧声音；已关闭或替换的预览不会用迟到结果或错误更新当前界面。图片读取不依赖侧栏触发按钮继续挂载，过滤或重建清单不会使有效预览停留在读取状态。

音视频支持按内容识别的 MP3、WAV、Ogg、MP4/M4A 和 WebM，每项最多 32 MiB；实际编码能否播放取决于系统 WebView。资源和附件清单只在点击后读取，播放器提供原生网页播放控件且不自动播放。正文 Sound/Movie 动作复用共享动作调度，支持音量、循环、同步声音等待，以及视频 Play/Stop/Pause/Resume；图元影片优先嵌入其外观区域，页面回收后移入可关闭的弹出播放器，其他情况直接使用弹出播放器。一次只保留一个音视频实例或待处理读取，新媒体替换旧媒体。包内资源（含模板独立资源）按所属文档体访问权限读取，不要求导出权限；附件仍要求导出权限，复用已加载播放器和再次播放时重新检查所属文档体权限。读取中可用 `×`/`Esc` 关闭；关闭、媒体切换、侧栏或文档切换会取消待处理请求，暂停播放、清除媒体源并回收 URL，解码不支持时提示另存为，不自动调用外部播放器。播放列表、远程媒体地址和未识别格式不进入播放器。

外部链接仅允许无用户名/口令的 HTTP/HTTPS 绝对地址，最多 4096 字节，拒绝控制字符、反斜线及不合法端口。每次由原生对话框展示完整地址，国际化域名转换为 ASCII 形式以便核对，默认“取消”；确认后交给系统浏览器，不让文档导航宿主 WebView，不启动任意协议处理器或本机程序。确认前后均检查原文档体的访问权限；取消、关闭或切换文档后不打开旧链接。系统浏览器可能访问网络，阅读器不预取链接目标。

动作语义依据 GB/T 33190—2016 第 12 章及 14.3–14.6（表 55–59）；内置预览、格式白名单、容量上限和外链确认是阅读器的安全策略，不是 OFD 标准额外要求。页面进入/文档打开自动动作尚未接入桌面端。

支持通过原生保存对话框导出原始签名值 `.dat`，以及印章/外层证书的 DER、PEM 文件；导出不代表签名有效或证书可信，不重新签名、不导出私钥。桌面端在对话框前及实际读取时检查所属文档体的导出权限和访问权限，输出最多 64 MiB（PEM 包含编码膨胀），沿用取消、旧会话隔离及输入文件链接保护；导出数据不传给网页，不自动打开或执行。数据缺失或参数无效时不显示保存对话框。
复制前重新检查文档权限，复制还需要系统 WebView 提供安全剪贴板；文档权限不是
操作系统级防复制机制。搜索最多扫描 2000 页、返回 5000 条。

打开对话框记住上次所选文件的目录，重启后继续使用；取消不改变记录，目录失效时使用系统默认位置。目录记录保存在系统用户配置目录的 `ofd-viewer-wails/open-directory`，不保存文件名或文档内容。
最近文档最多保留五条，按成功打开顺序更新，在同目录的 `recent-files.json` 保存本机绝对路径、名称、大小、打开时间和标识，不缓存文档内容。网页仅获得标识与显示元数据；清除记录不删除或关闭文档。原生拖放使用一分钟内有效的一次性标识，一次只接收一个普通 OFD 文件。

字体优先使用文档内嵌字体，缺失时由原生引擎查找系统字体；桌面端不显示浏览器专用的“使用系统字体”授权选项。
右上角“更多 → 关于”与浏览器版共用，未打开文档也可使用，工具栏不重复显示程序标题；对话框按运行端显示程序名称、字体策略和技术栈。桌面版本读取构建注入的发行版本，与 `--version` 一致。点击版本链接由系统浏览器打开固定的项目主页，不导航阅读器窗口。

导出入口支持 PNG、JPG、SVG、PDF、TXT，复用共享导出设置并通过原生对话框保存；使用当前图层，在保存对话框前、生成前及写入前检查全部所选页面的导出权限。所有格式均支持当前页、全部页面及自定义范围，一次最多 200 个不重复页面。单页图片直接保存，多页 PNG/JPG/SVG 保存为 ZIP，条目按所选页序排列，并以 `001-page-2.png` 等名称记录选择顺序和原页码。ZIP 使用不压缩存储；所有输出最多 64 MiB（含 ZIP 条目及目录开销）。PNG/JPG 的 DPI 为 1–600，每页最多 2500 万像素，保存对话框前检查全部页面大小；JPG 的透明背景使用白色。PDF 保留矢量和可用文字及页面物理尺寸，TXT 额外检查全部所选页面的复制权限，按位置合并文字为 UTF-8 纯文本，以 `\n\f\n` 分隔页面并保留空页边界，不还原复杂多栏、表格版式。SVG/PDF/TXT 不使用界面的 DPI 设置。不导出界面的缩放或临时高亮，禁止覆盖输入文档及其链接，取消或生成失败不提交部分文件。

### 加密、标签、历史版本与打印

- 支持 GM/T 0099-2020 口令和 SM2 证书加密文档。共享解锁框可输入口令，或通过原生文件对话框选择 UTF-8 口令文件、SM2 PKCS#8 PEM/DER 私钥（包括加密私钥），并填写接收者名称。口令文件最多 64 KiB，保留 BOM、空格、换行与空口令；私钥最多 4 MiB，文档最多 256 MiB。错误凭据可重试；取消或解锁失败保留原阅读会话。解锁标识五分钟内有效且不暴露本机路径；文件变化后须重新打开。凭据不写入设置或最近记录，不产生明文 ZIP；关闭或替换文档时释放解密视图。最近列表再次打开仍需解锁。
- “更多 → 标签”显示自定义 XML 标签树，可过滤、展开和定位 ObjectRef；XML 及对象文字仅作为文本展示，定位前复核访问权限。读取失败显示错误，不冒充空清单。
- “更多 → 版本”加载历史入口，再次点击所选版本恢复主文档。先在独立 Reader 中准备目标版本，成功后取消旧操作、轮换原生资源地址，并重载权限、导航、图层、字体、搜索、标签和签章；失败保留旧版本。解密视图同样支持历史版本；普通源文件发生变化时须重新打开。阅读位置按版本隔离。
- 打印复用当前页、全部页面和自定义范围选择，一次最多 200 个不重复页面，保留所选页序与物理尺寸。Go 按当前图层以 150 DPI 白底生成受限页面图片（每页最多 2500 万像素，合计最多 64 MiB），在独立 Wails 窗口预览后点击“系统打印…”。不要求导出权限；准备时、读取预览资源和调用系统打印前检查打印权限。打印预览只保存在内存中，使用五分钟有效的随机地址且不缓存；关闭预览、替换文档或成功切换版本时释放。取消准备不产生文件或提交打印任务。
- 与浏览器一致，禁止打印或份数为零会拒绝操作；正数份额显示提示，系统对话框的份数、打印完成状态及累计用量不能由 WebView 可靠控制。打印是页面位图而非矢量 PDF，不附加浏览器生成的注解备注文字列表。正式系统打印对话框打开后的取消由系统处理。

打印预览的五分钟有效期从窗口发布开始计算；到期后主动关闭窗口并释放图片，无需再访问预览地址。手动关闭、替换预览及退出程序会停止旧的回收定时器；窗口创建期间取消也不会留下迟到预览。版本和标签清单在重复读取或切换文档时取消旧请求，忽略同一文档内的乱序响应。关闭期间迟到的解锁凭据会丢弃并清理临时引用；原生凭据对话框期间的取消保留为取消错误，不重新弹出凭据错误提示。

PDF/SVG/办公附件的内嵌预览、GIF 动画、TIFF 多页及更多媒体编码尚未接入。桌面版图形显示、原生对话框、系统浏览器、平台音视频解码、打印机与剪贴板仍需实机验证。

## 系统要求

系统支持范围由实际使用的 Go 工具链、Wails、系统 WebView 和构建产物的动态库依赖共同决定，
依赖版本以根目录 [go.mod](../../go.mod) 为准。运行程序不需要安装 Go、Node.js 或编译器；
Windows WebView2、Linux GTK/WebKit 等运行库仍需安装。

| 平台 | 系统版本与运行依赖 |
|------|--------------------|
| Windows | Windows 10/11，提供 AMD64/ARM64 构建入口，需要 Microsoft WebView2 Evergreen Runtime；当前安装包不捆绑、不静默下载运行时。正式构建不支持 Windows 7/8/8.1 |
| macOS | Go 1.27 构建的工具链下限为 macOS 13 Ventura。还需系统 WKWebView 支持界面所用的 JavaScript、CSS 和对话框功能；实际部署目标可能进一步提高要求 |
| Linux | 默认使用 GTK4 + WebKitGTK 6.0，需要 X11/Wayland 桌面图形环境及产物要求的 glibc、GTK、WebKit 等运行库；提供 AMD64/ARM64 构建入口 |
| Android | Android 7.0（API 24）及以上，ARM64 / x86_64；需支持现代 JavaScript、CSS、dialog 的系统 WebView。Wails Android 为实验性，仍需设备验证 |
| iOS | 未适配，无打包入口 |

Windows Server 2016 是 Go 工具链支持的下限之一，不代表当前阅读器已完成服务器系统适配；
仍需核对 WebView2 支持范围、桌面环境并实机验证。音视频解码、剪贴板和系统打印也取决于平台 WebView 与系统配置。

### Linux 发行版与构建产物限制

- Wails 官方列出的 Linux 支持环境为 Ubuntu 24.04 AMD64/ARM64；本项目以 Ubuntu 24.04+
  作为发行适配目标，其他发行版需按实际依赖和目标环境验证，不能仅凭存在 GTK4 判定兼容。
- 在 Ubuntu 26.04 环境中构建的 Wails 包可能要求 glibc ≥2.38，不能直接用于默认 glibc 2.35 的 Ubuntu 22.04。
  这只是特定构建的例子，不是固定的全局最低版本；安装包的实际依赖和二进制符号要求才是依据。
- glibc 满足不代表 GTK/WebKit 的符号版本也满足。要支持 Ubuntu 24.04，应在 24.04 环境中构建并验证，
  不应只修改 DEB/RPM 的依赖声明或在更高版本系统编译后直接复制产物。
- DEB/RPM 会记录从二进制提取的 glibc 下限；ZIP 不会自动安装运行库。
  当前打包配置针对默认 GTK4 后端，不承诺旧 GTK3 后端或通过该后端兼容 Ubuntu 22.04。

上述条件不是全平台实机认证：交叉编译成功、包结构检查通过，均不能替代真实系统上的窗口显示、文件关联、打印与媒体验证。
macOS 下限看实际构建工具链而不是 `go.mod` 的最低 Go 版本；使用 Go 1.27 构建时不能仍宣称支持 macOS 12。
参考 [Go 系统最低要求](https://go.dev/wiki/MinimumRequirements) 与
[Wails 安装及平台要求](https://v3.wails.io/getting-started/installation/)。
与无需 WebView 的 Fyne 版比较，见 [根 README 对照表](../../README.md#桌面版系统要求对照)。

## 从源码运行

在具备 Wails 3 平台开发依赖的环境运行：

```sh
go run ./cmd/ofd-viewer-wails
go run ./cmd/ofd-viewer-wails -- "含空格的文件.ofd"
```

`--help` / `-h` 显示用法，`--version` / `-v` 显示版本。退出码：0 为正常退出、
1 为启动或运行错误（含启动路径不存在、无法访问或不是普通文件）、2 为参数错误。
命令行一次只接受一个 `.ofd` 文件（扩展名不区分大小写），以 `-` 开头的文件名前使用 `--`。
文档解析、解锁等交互阶段错误在界面中显示，不关闭正在运行的阅读器。

## Android 构建与差异

Android 直接运行相同的 Go 阅读引擎和共享 HTML/CSS/`viewer.js`，不包含 WASM，
不启动 localhost 服务。请从应用内“打开”选择文档；暂不注册文件管理器外部打开或分享接收入口。

- 使用系统文档选择器（SAF）打开。导入最多 512 MiB 的副本到应用私有目录，
  不修改原文档；加密文档仍受解密预算限制。最近五条记录保留导入副本，
  当前文档及待解锁文档也会保留，过期副本在后续打开或重启时清理。
  凭据文件读完即删除导入副本，不写入最近列表。卸载应用会删除私有数据。
- 页面、附件、资源、签名值及证书导出使用系统“创建文档”选择位置，不调用 Wails
  不支持的保存对话框。选择后重新检查权限，完整生成后才打开目标；用户取消不开始写入。
  SAF Provider 不支持桌面式同目录原子替换，系统创建的空文件或写入失败/取消留下的部分文件
  可能需要自行删除。页面导出仍最多 200 页 / 64 MiB，不绕过文档导出或复制权限。
- 返回键先关闭弹层、菜单和侧栏，无待关闭界面时退到后台；进入后台关闭媒体与预览，
  返回后须重新读取和检查权限。不创建第二个窗口。
- 暂不支持原生打印，隐藏打印按钮；快捷键也会给出提示。仅在允许导出时可保存 PDF，
  再自行使用其他应用打印；不把打印权限当成导出权限。
- 配置、临时文件和最近副本位于应用私有目录。关闭 Android 自动备份；Manifest
  仅声明 Wails WebView/网络监听所需的 INTERNET、ACCESS_NETWORK_STATE，不申请存储、相机或定位权限。
- 中英文与桌面相同。“关于”标明 Android；字体和媒体编码仍取决于系统环境。

构建主机支持 Linux/macOS，需要 Go、Python 3（安装 `cairosvg`，由共享 SVG 生成应用图标）、JDK 17+、Android SDK（API 36）
及 NDK（建议 r28+，支持 16 KiB 页面）。首次打包 Gradle 会联网下载依赖。
生成工程来自 `go.mod` 锁定的 Wails 模板，不修改模块缓存，模板适配点变化会显式失败。
如需使用已安装的兼容 Gradle，可设 `WAILS_ANDROID_GRADLE=/path/to/gradle`，
也可附加 `--offline` 等参数；默认使用框架模板的 Gradle wrapper。

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/<已安装版本>"
make build-wails-android                  # 仅生成 ARM64 libwails.so
make package-wails-android                # 可安装的 debug APK
make package-wails-android WAILS_ANDROID_ARCH=amd64  # x86_64 模拟器
make bundle-wails-android WAILS_ANDROID_RELEASE=1 WAILS_ANDROID_VERSION_CODE=2
```

APK/AAB 输出到 Makefile 的 `DIST_DIR`；构建工程位于 `BUILD_DIR/wails-android/<架构>`。
默认构建单 ABI debug 包，不是商店发布版本。`WAILS_ANDROID_RELEASE=1` 时可通过
`ANDROID_KEYSTORE_FILE`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、
`ANDROID_KEY_PASSWORD` 注入发布签名；未提供密钥则生成未签名 release 包，不回退调试签名。
版本名与 Go 关于版本均来自 Makefile `VERSION`；每次商店上传须递增 `WAILS_ANDROID_VERSION_CODE`。
脚本失败返回非零；Android 不提供桌面 CLI 参数与退出码接口。

回归入口：`python3 cmd/ofd-viewer-wails/packaging/android/test_build.py`、
`go test ./cmd/ofd-viewer-wails`、`make test-wasm-web`。
构建通过不代表完成设备验收：系统选择/保存、中文字体、返回键、前后台与内存回收仍需实机验证。

## 系统打开与默认阅读器

- 命令行文件、Windows/Linux 文件关联及 macOS Finder 打开事件共用原生打开流程。
  已运行时由单实例转发，恢复阅读器窗口；相对路径按发起进程的工作目录解析。
  界面未就绪或正在保存、解锁、导出时请求留在原生有界队列中，空闲后逐个处理（最多 16 个，超限写入诊断）。
  成功后照常更新最近文档和对话框目录，加密文件仍需解锁。网页不能传入任意本机路径。
- Linux 安装 DEB/RPM 后，文件管理器的“打开方式”中可选 **OFD Reader (Wails)**，也可双击已经关联的 OFD。
  “更多 → 设置为默认阅读器”通过 `xdg-mime` 设置并再次查询确认；失败保留系统错误。
  桌面文件未安装或处于 Flatpak 时隐藏该入口；探测失败不冒充“不是默认”。
- Windows 安装程序在当前用户下注册 `.ofd` 候选、默认应用设置入口、开始菜单与卸载项。
  在“更多 → 默认阅读器设置”进入 Windows 默认应用设置，选择 OFD Reader (Wails)。不写入或绕过系统 `UserChoice`。
  需要 Microsoft WebView2 Evergreen Runtime；安装包不捆绑、不静默下载运行时。
- macOS 将 `OFD Reader.app` 放入“应用程序”；包内声明 OFD 文档类型，由 Finder 发送打开事件。
  “更多 → 默认阅读器设置”显示操作指引：选择 OFD 文件 → 显示简介 → 打开方式 → OFD Reader → 全部更改。

安装与升级仅登记候选，不自动抢占已有默认阅读器；卸载只移除自身登记和文件，不删除用户文档或设置。
Windows/macOS 的真实文件关联、窗口唤醒及原生对话框仍需对应系统实机验证。

## 界面语言

“更多 → 语言 / Language”可选 **简体中文** 或 **English**，默认中文，选择保存到用户配置目录
`ofd-viewer-wails/language`，重启后保留。切换会刷新界面并重新打开当前文件，加密文档须重新解锁，
不持久化口令或私钥；未保存的临时选择会重置，打印预览会关闭。
菜单、侧栏、状态提示、导出/解锁界面、打印预览与原生对话框使用同一语言。
系统文件选择器及打印对话框内的系统按钮语言由操作系统决定；底层引擎原始错误可能保留中文。

英文词典在 `locales/en.json`，复用旧版 `internal/localization/viewer` 的已有消息。
桌面宿主仅在提供英文脚本资源时解析共享 JavaScript 的文案常量和模板静态部分；
取消协议和字体名称保持不变，模板插值不翻译且不改变求值顺序。共享 Web 源码和浏览器版语言不受影响。
静态 HTML 外壳只在载入时翻译一次，不监听后续 DOM；文档正文、文件名、属性和附件内容不会被翻译。

## 构建与安装包

Ubuntu 默认 GTK4 后端依赖：

```sh
sudo apt install build-essential pkg-config libgtk-4-dev libwebkitgtk-6.0-dev libx11-dev
pkg-config --modversion gtk4 webkitgtk-6.0
make build-wails
make package-wails
make package-wails-linux  # DEB + RPM，需要 nfpm、readelf
```

这些都是显式入口，不改变正式 Fyne 阅读器或默认 `make` 的发行范围；所有版本来自 Makefile 的 `VERSION`。
Make 目标仍使用简写 `build-wails` / `package-wails`，产物统一以 `ofd-viewer-wails` 命名；
Linux 系统包名为 `zc310-ofd-viewer-wails`。应用 ID、桌面 ID 和 Windows 安装注册键不随程序名变化，避免重复系统关联。
产物路径沿用 Makefile 的 `DIST_DIR` / `BUILD_DIR`，可在命令行覆盖。
DEB/RPM 依赖 GTK4、WebKitGTK 6、X11 与桌面 MIME 工具，刷新 MIME、图标和桌面缓存；
与 `ofd-viewer` 使用独立的程序名、桌面 ID 和文件路径，可并存。
Linux ZIP 提供二进制、README、许可声明、桌面文件、SVG 图标和 MIME XML；便携 ZIP 不自动安装系统关联。

Windows 构建安装包（需要 NSIS；可在 Linux 交叉构建，纯 Go 路径无需 MinGW）：

新安装默认目录为 `%LOCALAPPDATA%\Programs\zc310\ofd-viewer-wails`，可在安装向导中修改。
安装目录与应用能力记录位于 `HKCU\Software\zc310\OFD Reader Wails`；卸载保留共享的 `Software\zc310` 父键。
升级沿用已记录的安装目录，不自动迁移旧安装；卸载只移除自身文件和应用目录，不删除共享的 `zc310` 父目录。

```sh
make GOOS=windows GOARCH=amd64 CGO_ENABLED=0 package-wails
make GOOS=windows GOARCH=amd64 CGO_ENABLED=0 package-wails-installer
```

Windows 构建会用固定版本的 `go-winres` 为 EXE 写入图标资源（保留原有资源，签名应在此步骤后进行），
无需 MinGW 或在源码目录生成 `.syso`。可通过 `WAILS_WINRES=/path/to/go-winres` 使用预装工具。
开始菜单快捷方式、文件关联、安装/卸载程序及“已安装的应用”使用同一图标；便携 ZIP 也包含 `icon.ico`。
图标直接复用桌面版 `cmd/ofd-viewer/share/io.github.zc310.ofd.svg`，
保留蓝、红、绿三圆 OFD 标识及 OFD Viewer 字样，包含 16–256px 尺寸和透明圆角。
ICO 是自动生成且不提交 Git 的构建产物。Windows 的 `build-wails`、`package-wails` 和
`package-wails-installer` 会在图标缺失、SVG 或生成脚本更新时自动生成它；Linux/macOS 构建不需要图像生成依赖。
Windows 构建前请在 Python 环境中安装 `CairoSVG` 和 `Pillow`（例如 `python3 -m pip install CairoSVG Pillow`），
并准备 Cairo 动态库。可用 `WAILS_PYTHON=/path/to/venv/bin/python` 指定 Python 环境。
也可运行 `python3 cmd/ofd-viewer-wails/packaging/generate_icon.py` 手动重建。
升级安装会重新创建开始菜单快捷方式；手动复制到其他位置的旧快捷方式需重新创建或在属性中更换图标。

macOS 请在目标 macOS 上执行 `make package-wails`，ZIP 内包含可移入应用程序目录的 `.app`，
并保留程序执行权限。当前打包入口不执行开发者签名、公证或生成 DMG；发布前需自行完成这些发行步骤。

验证（测试不会实际更改默认应用）：

```sh
go test ./cmd/ofd-viewer-wails -count=1
go test -race ./cmd/ofd-viewer-wails -count=1
go vet ./cmd/ofd-viewer-wails
node --test cmd/ofd-viewer-wails/test/*.test.mjs
make test-wasm-web
python3 -B -m unittest discover -s cmd/ofd-viewer-wails/packaging -p '*_test.py'
```

设置 `WAILS_WINDOWS_EXE=/path/to/ofd-viewer-wails.exe` 后运行上述 Python 测试，还会检查真实 EXE 中
Wails 使用的图标资源 ID 3、各尺寸图像及资源引用，避免只检查安装脚本文本而漏掉 EXE 图标。
